คนที่มีสิทธิ์

ถ้ามือถือหาย

  1. ใช้รหัสกู้คืน 2FA ที่จดเก็บไว้ เข้าจากเครื่องอื่น แล้วกด "ออกจากระบบ" — ระบบออกจากทุกเครื่องในครั้งเดียว รวมมือถือที่หาย
  2. เปลี่ยนรหัสผ่าน Google ของอีเมลนั้น และถอดมือถือเครื่องที่หายออกจากบัญชี Google
  3. ถ้ายังกังวล เอาอีเมลนั้นออกจาก ADMIN_EMAILS บน Render ชั่วคราว (บัญชีของแม่ยังใช้แทนได้)
  4. เข้า Render และ GitHub ด้วยรหัสกู้คืนของแต่ละที่ — สองบัญชีนี้ควบคุมทั้งระบบ
