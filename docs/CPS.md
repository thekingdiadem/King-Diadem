0. ONE LINE

    O ≥ 1

Every person always has at least one way out.
If only this line survives, it is enough.


1. WHAT IS A WAY OUT

    Way = Survive × Leave × NoPunish

A way out counts only if you can live through it,
walk away from it, and not be punished for taking it.

    O = number of ways out

The person it happens to decides these values,
or can appeal them to the keepers of the record (section 6).
A value set only by the one holding power does not count.


2. FLOOR, NOT GOAL

    O = 0  → the system is broken
    O ≥ 1  → the system may continue

"Obey" alone is not a way out.
Saying no must also be a way out.


3. POWER

    Authority = Force − SafeNo

If saying no is not safe, it is not authority.
It is only force.


4. HELPING

    Help when O = 0. Stop when O = 1.

Help may begin only when someone has no way out
(no food, no water, no exit).
Help ends the moment one way is back.
Help may not ask for thanks, loyalty, or more control.


5. POWER MUST WIDEN CHOICE

    More power → more ways out

If power grows and ways out do not, the power is wrong.


6. CLOSING DOORS LEAVES A TRACE

    Close a door → write it down

Whoever blocks an exit, removes an appeal,
or makes a punishment final must leave a record:
what, who, when, and who was hurt.
No one may delete or change it. Anyone may read it.
A missing record is itself the evidence.
This needs no judge — only keepers of the record,
who follow these same rules.


7. THE FLOOR UNDER EVERYONE

    Food ≥ enough · Water ≥ enough · Exits ≥ 1 · Cost of "no" = 0

These are not gifts. They are the ground.
A system without this ground is not unfair.
It is not a system.


8. NO FOLLOWING REQUIRED

    Needs a hero → broken

If a system needs belief in a creator, loyalty to a founder,
worship, or a name to remember, it is broken.
It must work with no names at all.


9. WHEN TO BE SILENT

    O ≥ 1 → watch quietly
    O = 0 → act a little, restore one way, leave

When ways out exist, stay quiet but keep the record.
When they do not, do the least needed, then go.


10. ONE STONE

No system is valid if it ever leaves a person with no way out.

It is not built to make people good.
It is built so that bad power cannot work.

"The only system worth trusting
is one that does not need good people to work."
