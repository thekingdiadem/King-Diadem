# ส่ง KING DIADEM ขึ้น Google Play — ทีละขั้น

แอป Android ของ KING DIADEM คือเว็บเดิมที่ห่อด้วย **Trusted Web Activity (TWA)** — ไม่ต้องเขียนแอปใหม่
แก้เว็บเมื่อไร แอปเปลี่ยนตามทันที ไม่ต้องส่งอัปเดตเข้า Play ทุกครั้ง

สิ่งที่โค้ดเตรียมไว้แล้ว (ตรวจด้วย `tests/test_play_store.py`):

| สิ่งที่ Play ต้องการ | อยู่ที่ |
|---|---|
| ไฟล์ตั้งค่าแอป | `android/twa-manifest.json` (ใช้กับ Bubblewrap) |
| ยืนยันว่าเว็บกับแอปเป็นของเจ้าของเดียวกัน | `/.well-known/assetlinks.json` (อ่านค่าจาก `TWA_PACKAGE` + `TWA_SHA256` บน Render) |
| Web manifest · ไอคอน 512 · ไอคอน maskable · ภาพหน้าจอ | `static/manifest.json` · `static/icons/` · `static/screenshots/` |
| นโยบายความเป็นส่วนตัว | https://king-diadem.onrender.com/privacy |
| ลบบัญชีได้เองในแอป และมีลิงก์บนเว็บ | แท็บ “เครื่องมือ” → “ลบบัญชี” · https://king-diadem.onrender.com/privacy#delete |
| รายงานคำตอบของ AI ในแอป (นโยบาย AI-generated content) | ปุ่มธงใต้ทุกคำตอบ |
| เบอร์ฉุกเฉินกดโทรได้ | ทุกคำตอบเรื่องด่วน |

## ขั้นที่ 1 — สร้างแอปบนคอม (ครั้งเดียว ~30 นาที)

ต้องมี: Node.js 18+ และ Java 17 (Bubblewrap ติดตั้ง Android SDK ให้เองตอนรันครั้งแรก)

```bash
npm install -g @bubblewrap/cli
cd android
bubblewrap init --manifest https://king-diadem.onrender.com/static/manifest.json   # ตอบตามค่าใน twa-manifest.json
bubblewrap build                                                                      # ได้ app-release-bundle.aab
```

ตอนแรกระบบจะสร้าง **กุญแจเซ็นแอป** `android.keystore` และถามรหัสผ่าน

> ⚠ **กุญแจนี้สำคัญที่สุดในทั้งกระบวนการ** — หายแล้วอัปเดตแอปเดิมไม่ได้อีกเลย รั่วแล้วคนอื่นปลอมแอปได้
> เก็บไฟล์ + รหัสผ่านไว้ 2 ที่ (เช่น Google Drive ส่วนตัว + USB ที่บ้าน) · `.gitignore` กันไม่ให้เข้า git แล้ว
> แนะนำให้เปิด **Play App Signing** (ค่าเริ่มต้นของ Play) — Google เก็บกุญแจหลักให้ ถ้ากุญแจอัปโหลดหายยังขอเปลี่ยนได้

## ขั้นที่ 2 — ผูกเว็บกับแอป

```bash
bubblewrap fingerprint list        # หรือดูใน Play Console → Setup → App signing → SHA-256
```

บน Render → Environment ตั้ง:

```
TWA_PACKAGE=com.kingdiadem.app
TWA_SHA256=<ลายนิ้วมือจาก Play App Signing>,<ลายนิ้วมือของกุญแจอัปโหลด>
```

เปิด https://king-diadem.onrender.com/.well-known/assetlinks.json ต้องเห็นชื่อแพ็กเกจและลายนิ้วมือ
(ถ้าไม่ผูก แอปยังเปิดได้แต่จะมีแถบที่อยู่เว็บโผล่ด้านบน)

ลายนิ้วมือเป็นข้อมูลสาธารณะ ไม่ใช่ความลับ

## ขั้นที่ 3 — Play Console

1. สมัคร Google Play Console (ค่าธรรมเนียมครั้งเดียว 25 USD) · บัญชีส่วนตัวใหม่ต้องทดสอบแบบปิดกับผู้ทดสอบ 12 คน 14 วันก่อนเปิดสาธารณะ
2. Create app → อัปโหลด `app-release-bundle.aab` เข้า **Internal testing** ก่อน ลองบนมือถือตัวเอง
3. กรอกตามหัวข้อด้านล่าง

## หมายเหตุสำคัญ: การชำระเงิน

นโยบาย Google Play: ของดิจิทัลที่ขายในแอป (เครดิต · แพ็กเกจ) ต้องจ่ายผ่าน **Google Play Billing**
ตอนนี้เว็บรับเงินผ่าน Stripe — ถ้าแอปบน Play พาไปหน้าจ่ายเงิน Stripe มีโอกาสถูกปฏิเสธ

ทางที่ปลอดภัยสำหรับเวอร์ชันแรก (เลือกหนึ่ง):
1. **แอปฟรีล้วน** — ในแอปไม่แสดงปุ่มซื้อเครดิต (ใช้ได้วันละ 20 ข้อความ) คนที่อยากจ่ายไปจ่ายบนเว็บเอง
2. ใช้โครงการ **User Choice Billing / alternative billing** ที่ Google เปิดในบางประเทศ (ต้องสมัครแยก)
3. ต่อ Google Play Billing ผ่าน Digital Goods API (งานโค้ดเพิ่ม)

> ยังไม่ได้ทำในโค้ด — รอเจ้าของโปรเจกต์เลือกทาง

## หลังเปิดตัว
