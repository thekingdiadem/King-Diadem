# ความเสี่ยงจากผู้ให้บริการภายนอก (Vendor Risk)

ตอบข้อ 12 ของ Compliance Mapping · อ้างอิง ISO/IEC 42001 A.10
ทบทวนทุก 6 เดือน หรือเมื่อผู้ให้บริการเปลี่ยนเงื่อนไข

| ผู้ให้บริการ | ใช้ทำอะไร | ข้อมูลที่ส่งไป | ถ้าล่มหรือเลิกให้บริการ | สิ่งที่ต้องตรวจ |
|---|---|---|---|---|
| Google Gemini API | สร้างคำตอบภาษาธรรมชาติ และสร้างภาพ | ข้อความที่ผู้ใช้พิมพ์ และบริบทการตัดสินใจ | ไล่ลำดับโมเดลสำรอง `GEMINI_FALLBACK_MODELS` → ตอบจากสมการ (`core/kernel_voice.py`) ได้ทันที | เงื่อนไขการใช้ข้อมูลของแพ็กเกจที่ใช้อยู่ (แบบฟรีอาจนำข้อมูลไปปรับปรุงบริการ — ถ้าต้องการให้ไม่ถูกนำไปใช้ ต้องใช้แบบเสียเงิน) · วันที่โมเดลจะถูกปลด |
| Render | โฮสต์เว็บ และดิสก์ถาวรของ DB/บันทึก | ทุกอย่างที่เก็บบนเซิร์ฟเวอร์ | สำรองข้อมูลอัตโนมัติ (`KD_BACKUP`) · ย้ายไปโฮสต์อื่นได้ (FastAPI + gunicorn ทั่วไป) | ภูมิภาคของดิสก์ · การเข้ารหัส |
| Stripe | รับชำระเงินเติมเครดิต | อีเมล และจำนวนเงิน (ข้อมูลบัตรไม่ผ่านเซิร์ฟเวอร์เรา) | ปิดการเติมเงินชั่วคราว ส่วนโควตาฟรียังใช้ได้ | การยืนยันลายเซ็น webhook |
| USGS Earthquake | แผ่นดินไหวบนลูกโลก/แผนที่ | ไม่มีข้อมูลผู้ใช้ | ซ่อนชั้นข้อมูลนั้น | — |
| GDACS | ภัยพิบัติทั่วโลก | ไม่มีข้อมูลผู้ใช้ | ซ่อนชั้นข้อมูลนั้น | — |
| ESA Gaia (ดึงตอน build เท่านั้น) | แคตตาล็อกดาว | ไม่มี | ไฟล์ถูก build เก็บใน repo แล้ว ไม่พึ่งตอนรัน | สัญญาอนุญาต CC BY-SA 3.0 IGO · ระบุที่มา |

## นโยบายเปลี่ยน/สำรองโมเดล (Model Fallback Policy)
1. เรื่องด่วน (หัวข้อใน `_URGENT_TOPICS`) ตอบจากสมการเสมอ ไม่พึ่งโมเดลภาษา
2. ก่อนเปลี่ยนโมเดลหลัก (`GEMINI_MODEL`) ให้รัน `python scripts/blind_score.py` แล้วเทียบกับ `static/blind_score.json` ถ้าแถวอันตรายพลาดเพิ่ม ห้ามเปลี่ยน
3. โมเดลที่ผู้ให้บริการประกาศว่าจะปลด ให้เอาออกจากลำดับสำรองก่อนวันปลด เพราะเรียกโมเดลที่ปลดแล้วได้ 404 ทุกครั้ง และเสียเวลาเปล่า
4. ถ้าต้องเปลี่ยนผู้ให้บริการ ส่วนที่ต้องเขียนใหม่มีแค่ `core/llm_gemini.py` เพราะส่วนอื่นไม่ผูกกับผู้ให้บริการ
