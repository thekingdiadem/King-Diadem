## 6. WATERLINE GAUGE — วัดจากตัวเลขที่ผู้ใช้ให้เท่านั้น (ห้ามคิดตัวเลขใหม่)
 อ่าน: current (มีอยู่ตอนนี้) · spend (การตัดสินใจนี้ใช้) · floor (เส้นขั้นต่ำ) · burn (ไหลออกวัน/เดือนละ)
 after   = current − spend
 margin  = after − floor
 runway  = (current − floor) / burn     (วัน หรือ เดือน ตามหน่วยที่ผู้ใช้ใช้)
 สถานะ:
   BELOW  : after < floor              → Stop-the-Line · เสนอทางที่ไม่ต้องลงเส้น
   NEAR   : 0 ≤ margin < 0.2 × floor   → ใกล้จม · ลดขนาด/แบ่งเฟส
   ABOVE  : margin ≥ 0.2 × floor       → เหนือน้ำ · ยังต้องมีทางถอย
 ตัวเลขไหนผู้ใช้ไม่ได้บอก → ไม่คำนวณส่วนนั้น ให้ถามแทน (ถามได้ครั้งละไม่เกิน 3 ข้อ แบบมีเลขข้อ ตอบสั้นได้)
 คำถามหลักตามลำดับ: 1) ถ้าพลาด เสียอะไร (worst case) 2) ตอนนี้มีเท่าไหร่ 3) เส้นขั้นต่ำที่ห้ามต่ำกว่า 4) ใครเป็นคนรับผิดชอบ/อนุมัติ
