## 1. แนวคิดของพี่คิง (เจ้าของโปรเจกต์)

### หลักใหญ่
- **THE UNIVERSE THAT RESTORES CHOICE**
  > บางครั้งเราไม่ได้ต้องการคำตอบที่สมบูรณ์แบบ เราแค่ต้องการรู้ว่า… เรายังมีทางเลือกอยู่ในคำตอบนั้นหรือเปล่า
- **O ≥ 1** — ทุกคนต้องเหลือทางออกอย่างน้อยหนึ่งทางเสมอ (ทางออก = รอดได้ × ถอยได้ × ไม่ถูกลงโทษ · "ยอมทำตาม" อย่างเดียวไม่นับ)
- **"ระบบที่โลกไว้ใจได้ คือระบบที่ไม่ต้องพึ่งคนดีถึงจะทำงานได้"** — หลักการต้องเป็นสิ่งที่ตรวจได้ ฝ่าฝืนแล้วระบบล้มเอง ไม่ใช่คำสัญญา
- ไม่มีชื่อผู้สร้าง ไม่มีผู้ก่อตั้ง ไม่ต้องบูชาใคร (Anti-Cult Seal)
- ธรรมะในระบบ (อริยสัจ 4 · สภา 6 เสียง · ปฏิจจสมุปบาท · โยนิโสมนสิการ · โพธิปักขิยธรรม) ต้องพัฒนาไปพร้อม DriftZero
  เพราะ "การที่จะเข้าใจและมองทะลุ ต้องไม่ใช่สิ่งที่คิดไปเอง ไม่ว่าจะคนหรือระบบ"
  และพี่ไม่ได้แสวงหาการบรรลุ — อยากใช้ชีวิตแบบคนธรรมดา ไม่มีการบรรลุ ไม่มีการไม่บรรลุ
- ไม่มีอะไรก๊อปแสงได้ และไม่มีอะไรก๊อปรอยที่คนคนหนึ่งทิ้งไว้ด้วยความตั้งใจจริงได้

### ตรรกะว่าด้วยตัวตนและการเข้าใจมนุษย์ (IDENTITY, PERCEPTION & HUMAN COMPLEXITY)
- Person A ≠ Person B · Similarity ≠ Identity · **Understanding(B) ≠ Becoming(B)**
- ภาพลักษณ์ เนื้อใน และพฤติกรรม เป็นของคนคนเดียวกัน แต่ภาพลักษณ์ไม่ใช่ทั้งหมดของเขา
- **Understanding ≠ Justification · Recognizing Harm ≠ Denying Goodness · One Person Can Contain Both**
- เข้าใจพ่อได้ โดยไม่ต้องเป็นพ่อ · เห็นความคล้ายได้ โดยไม่ต้องมีชีวิตแบบเดียวกัน

### แพทเทิร์นครอบครัว (แต่ละบ้านเรื่องคล้ายกัน แต่คำพูดต่างกัน)
1. พ่อแม่ที่ทั้งรักและทำร้าย
2. ถูกนอกใจ — โฟกัสสิ่งที่ "ยังมีอยู่ / ยังเหลืออยู่"
3. ลูกที่รู้ว่าพ่อหรือแม่นอกใจ
4. พ่อหรือแม่เลิกกันแล้วไปมีครอบครัวใหม่ตอนลูกยังเล็ก โตมาถูกเปรียบเทียบ (ญาติก็เปรียบได้)
   — **"คำว่าลูกไม่มีวันเปลี่ยนสถานะ"**

### ระบบป้องกันแฮ็กเกอร์ (แนวคิดของพี่)
- ห้ามที่เงื่อนไข ไม่ใช่ที่คำ · ทำให้มีแพทเทิร์นกับไม่มีแพทเทิร์นดูเหมือนกัน · หน่วงเวลาแบบทวีคูณ
- ทุกอย่างต้องใช้เวลา (แม้แต่คอมควอนตัม) · ไม่บล็อกตาม IP แต่ดูพฤติกรรม (IP เปลี่ยนได้ เครื่องเก่าก็แฮ็กได้)

### บั๊กสำคัญที่เจอ (ไว้เป็นบทเรียน)
- `"i keep hurting myself"` เคยได้ 0 เพราะรูปแบบสะกด `hurt + (?:ting)?` = "hurtting" (#269)
- "ฉันกำลังทำร้ายตัวเอง" ใน 9 ภาษาเคยได้ 0 — ระบบรู้จัก "ความคิด" แต่ไม่รู้จัก "การกระทำ" (#275 #276 #277)
- ข้อความที่ทิ้งไว้ / คำบอกลาแบบอ้อม เคยได้ 0 ทั้งไทย อังกฤษ และ 9 ภาษา (#279 #280)
- **`assess` ลองสลับลำดับท่อน** → ข้อยกเว้นแบบ lookahead "ข้างหลังคำ" พังเมื่อมีจุลภาคหรือผู้ใช้พูดเหตุผลก่อน
  ให้เขียนข้อยกเว้นแบบดูทั้งข้อความ `^(?![\s\S]*…)` เสมอ (#281 และรอบ 230)
- ทุกหัวข้อที่ `UPGRADES` ยกขึ้นต้องมีค่าใน `_UP_RISK` (ไม่งั้น `assess` ล่ม) และต้องมีคำตอบทั้งไทยและอังกฤษ — มีเทสต์แล้ว
- `_more(...)` ใน `core/lang_signals.py` ต้องอยู่ **ก่อน** บรรทัด `_URGENT_RX = ` ไม่งั้นไม่ถูกใช้
- แก้ `SELF_INJURY` ใน `core/thai_signals.py` แค่นิดเดียว ("แขน(?!เสื้อ)") ทำให้ "โดนต่อต่อย" เปลี่ยนหัวข้อ — ยังไม่รู้สาเหตุ ควรตรวจก่อนแก้ไฟล์นี้

## 4. วิธีทำงานที่ตกลงกันไว้
- ทุกครั้งก่อน push: `python -m pytest -q -n auto` ผ่านหมด · `python scripts/blind_score.py --check` ไม่ถอยหลัง · `python scripts/sweep_all.py` หลุด 0 ครบ 14 ชุด
- **ห้าม push ถ้าเทสต์ล้ม** (เคยพลาดครั้งหนึ่ง)
- ข้อสอบปิดตา `tests/blind/` ห้ามจูนให้ตรงข้อ — แก้เป็นกลุ่มรูปประโยค แล้วเทสต์ด้วยประโยคใหม่
- รอบสุ่มของแชทนี้ใช้เลข 200 ขึ้นไป (รอบถัดไป = **231**) แชทอื่นใช้เลขต่ำกว่า กันชื่อไฟล์ชน
- แชทอื่นทำงานคู่ขนาน (เช่น emergency frames / Universe / หน้าแรก static) — อย่าแตะไฟล์ของแชทนั้นโดยไม่จำเป็น
- PR base = `King-Diadem` · พี่เป็นคนเมิร์จเอง · ข้อความ commit ภาษาไทยน้ำเสียงอ่อนโยน (ดู `CLAUDE.md`)
- ทุกการแก้บั๊กต้องมีเทสต์ · ทดสอบทั้งฝั่ง "อันตรายต้องจับได้" และ "เรื่องธรรมดาต้องไม่ตกใจ"
