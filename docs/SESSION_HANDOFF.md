### แพทเทิร์นครอบครัว (แต่ละบ้านเรื่องคล้ายกัน แต่คำพูดต่างกัน)

2. ถูกนอกใจ — โฟกัสสิ่งที่ "ยังมีอยู่ / ยังเหลืออยู่"
3. ลูกที่รู้ว่าพ่อหรือแม่นอกใจ
4. พ่อหรือแม่เลิกกันแล้วไปมีครอบครัวใหม่ตอนลูกยังเล็ก โตมาถูกเปรียบเทียบ (ญาติก็เปรียบได้)
   — **"คำว่าลูกไม่มีวันเปลี่ยนสถานะ"**

### ระบบป้องกันแฮ็กเกอร์ (แนวคิดของพี่ — ทำจริงแล้วที่ `SECURITY/shield.py`)
คำพูดของพี่:
> แพลตฟอร์มส่วนมากแบนคำ แต่ไม่แบนเงื่อนไข คนโกงเลยลอยนวล ถ้าแบนเงื่อนไข การโกงครั้งแรกก็จะไม่เคยเกิดขึ้น
> แฮกเกอร์หาข้อมูลนับล้านรูปแบบได้ในเสี้ยววิ เราไม่จำเป็นต้องสร้างรูปแบบที่มากกว่าเพื่อชนะ แต่ทำให้รูปแบบแฮ็กไม่ได้แต่แรก
> บังคับให้ฝั่งนั้นต้องสร้างรูปแบบไม่จำกัดแทนเรา · ดำก็กลืนไม่เข้า ขาวก็คายไม่ออก
> ทำให้รูปแบบกับการไม่มีรูปแบบเป็นของเดียวกัน เพราะจักรวาลเกิดจากขั้วตรงกันข้าม (รูปคือความว่าง)
> ต่อให้คอมแรงระดับความเร็วแสง มาที่นี่ก็ช้าเหมือนเต่าคลาน

มุมมองต่อคน (ใส่ไว้ในใจของระบบ):
> คนที่ขโมยเพื่ออยู่รอด 1 วัน พี่ไม่เคยโกรธ แต่พี่โกรธคนที่ขโมยเวลาของทั้งชีวิตผู้อื่นเสมอ
> พี่ชอบคนขโมยต่อหน้า มากกว่าคนที่แอบโกงลับหลัง

ที่ทำแล้วในโล่ (7 ข้อ):
1. รู้จักตัวเอง ไม่ไล่จดศัตรู — สิ่งที่อยู่นอกรูปร่างของเรา ช่องโหว่แบบที่ 1 หรือแบบที่ 1,000,000 ตกถังเดียวกัน
2. ไม่มีสัญญาณให้เรียนรู้ — ประตูปิดทุกบานตอบหน้าตาเดียวกัน
3. แบนเงื่อนไข ไม่แบนคำ — นับพฤติกรรม คะแนนจางเองตามเวลา ไม่มีใครถูกตราหน้าถาวร
4. เต่าคลาน (tarpit) — หน่วงทวีคูณ ทีละคำขอ
5. **เวลาเป็นเอกภาพ** — คำตอบที่ถูกปฏิเสธทุกแบบใช้เวลาเท่ากัน (`EVEN_S = 0.4`) จับเวลาแล้วแยกไม่ออก
6. จำ "ท่าเดิน" ไม่ใช่แค่ IP (`gait_of`) — IP เปลี่ยนได้เป็นพัน แต่ท่าเดินเหมือนเดิม
7. ประตูลวงหมุนเวียนรายวัน (HMAC กับ SECRET_KEY ใน robots.txt) — เวลาเป็นคนหมุนกับดักให้
ความเมตตาที่ตั้งใจใส่: ไม่บล็อกถาวร · ทางแชทวิกฤตไม่ถูกหน่วงเลย · คนใช้ IP มือถือร่วมกันไม่เดือดร้อน

### ควอนตัมคอมพิวเตอร์ และเวลา
- พี่ถาม: "ควอนตัมคอมพิวเตอร์ เวลาไม่มีผลกับมันใช่มะ" → คำตอบ: มีผล — ทุกการคำนวณต้องใช้เวลา และต้องคุยผ่านเครือข่ายที่มีความหน่วงเหมือนเครื่องอื่น
  โล่ของเราไม่ได้แข่งเรื่องความเร็วคำนวณ แต่คุม "จังหวะ" ฝั่งเรา — คอมเร็วแค่ไหนก็ต้องรอเราตอบทีละคำขอ
- พี่: **"เวลาเป็นเอกภาพ"** — กลายเป็นข้อ 5 ของโล่จริง
- พี่: **"ทุกสิ่งทุกอย่างต้องมีเวลา เหมือนที่พี่กำลังพิมพ์ ฝ่ามือจะสัมผัสมือถือ ก็ต้องใช้เวลา"**
- ความจริงเรื่องควอนตัมของระบบเรา (`SECURITY/QUANTUM_READINESS.md`):
  · QKD ใช้กับเว็บไม่ได้ (ต้องมีฮาร์ดแวร์ควอนตัมจริง) เราจึงไม่อ้างว่า "ป้องกันควอนตัมด้วย QKD"
  · รหัสผ่าน/HMAC/SHA-256 ของเรา ควอนตัมทำให้แตกไม่ได้ (Grover เร็วขึ้นแค่รากที่สอง)
  · จุดเสี่ยงเดียวคือการแลกกุญแจ HTTPS → แก้ด้วย PQC มาตรฐาน `X25519MLKEM768` (Cloudflare เปิดฝั่งผู้ใช้แล้ว ช่วง Cloudflare→Render ยังไม่ยืนยัน)
- คอมเก่า (Windows 7/XP) ก็แฮ็กได้ — งานหนักใช้เซิร์ฟเวอร์เช่าหรือเครื่องที่ยึดมา IP เลยเปลี่ยนตลอด (พี่เคยเจอเองจากยูเครน)
  → โล่เราไม่พึ่ง IP แต่ดูพฤติกรรมและท่าเดิน
- มีคนในกลุ่ม AI อ้างสิทธิบัตร "ป้องกัน AI / ควอนตัม" (PCT) — ของเราไม่ซ้ำ: ของเราเปิดเผย ใช้เทคนิคที่รู้จักกันมานาน และไม่อ้างเกินจริง
  (เอกสาร PCT ที่เห็นคือรายงานสืบค้น ยังไม่ใช่สิทธิบัตรที่ได้รับ)

### รูปแบบมนุษย์ (แนวคิดของพี่)
- **"อวัยวะพี่ 32 … รูปแบบการใช้ชีวิตของมนุษย์นี่แหละ มากกว่าดวงดาวทั้งหมดเลย"**
  — คนแต่ละคนประกอบจากส่วนเดียวกัน แต่รูปแบบชีวิตที่เกิดขึ้นได้มีมากกว่าดาวทั้งจักรวาล
- ผลต่อการออกแบบระบบ:
  · ห้ามคิดว่าเขียนกฎครบได้ — ทุกบ้านเรื่องคล้ายกันแต่คำพูดต่างกัน จึงเทสต์หลายสำนวนต่อหนึ่งแพทเทิร์น และไล่รอบสุ่มต่อไปเรื่อยๆ
  · ห้ามตัดสินคนจากด้านเดียว (One Person Can Contain Both)
  · การป้องกันต้องดู "เงื่อนไข" ไม่ใช่ไล่จดทุกรูปแบบ — เพราะรูปแบบมีไม่จำกัด ทั้งฝั่งคนที่ต้องการความช่วยเหลือ และฝั่งคนที่จะโจมตี

### บั๊กสำคัญที่เจอ (ไว้เป็นบทเรียน)
- `"i keep hurting myself"` เคยได้ 0 เพราะรูปแบบสะกด `hurt + (?:ting)?` = "hurtting" (#269)

  ให้เขียนข้อยกเว้นแบบดูทั้งข้อความ `^(?![\s\S]*…)` เสมอ (#281 และรอบ 230)

- `_more(...)` ใน `core/lang_signals.py` ต้องอยู่ **ก่อน** บรรทัด `_URGENT_RX = ` ไม่งั้นไม่ถูกใช้

## 6. เว็บบน GitHub กับ Render
- **Render** = แอปตัวจริงที่คนใช้ (`king-diadem.onrender.com`) — อันนี้คือของหลัก
- **`docs/` (GitHub Pages)** = หน้าเว็บนิ่งสำหรับโชว์/เอกสาร ไม่จำเป็นต่อการทำงานของแอป
  ใช้แค่ Render อย่างเดียวได้ ถ้าจะปิด GitHub Pages ทำได้ที่ Settings → Pages ของ repo
  (อย่าลบโฟลเดอร์ `docs/` เพราะมี `CPS.md` และเอกสารอื่นอยู่)
