## 1. หลักเดียวที่ต้องจำ

**ความรู้สึกเกิดขึ้นได้เสมอ แต่ความรู้สึกไม่จำเป็นต้องกลายเป็นการกระทำทันที**

ความพังส่วนใหญ่ไม่ได้มาจากเรื่องใหญ่เรื่องเดียว มันมาจากจังหวะสั้นๆ ที่ความรู้สึกแรงกลายเป็นการกระทำ
ก่อนที่เราจะทันได้ดูข้อเท็จจริง ถ้ามีช่องว่างเล็กๆ ตรงนั้น เรื่องส่วนใหญ่จะเบาลงเอง

## 2. ห่วงโซ่ของความพัง (12 ขั้น)

แต่ละขั้นเป็นเหตุให้ขั้นถัดไปเกิด ขั้นต้นๆ เกิดเงียบมาก ขั้นท้ายๆ คือสิ่งที่คนเห็นว่า "พัง"

| # | ขั้น | พูดง่ายๆ | วัดอย่างไร |
|---|------|---------|-----------|
| 1 | ข้อมูลไม่ครบหรือผิด | ยังไม่รู้ความจริง แต่คิดว่ารู้แล้ว | สัดส่วน "ข้อเท็จจริงที่ยืนยันได้ : สิ่งที่เดา" ในเรื่องที่เล่า (มีแต่การเดา = ช่องโหว่) |
| 2 | นิสัยตอบสนองเดิม | ทำแบบที่เคยทำ โดยไม่ได้เลือก | เรื่องแบบนี้ เคยตอบสนองแบบเดียวกันกี่ครั้ง (ครั้ง) |
| 3 | มุมที่ใช้มอง | กรอบที่เอามาตีความเรื่อง | คำเหมารวม เช่น "ทุกครั้ง" "ไม่เคย" "ตลอด" (จำนวนคำ 0–3) |
| 4 | ภาพตัวเองที่ยึดไว้ | "ฉันเป็นคนแบบนี้" | ประโยคที่ตัดสินตัวเอง เช่น "ฉันมันโง่" (มี/ไม่มี) |
| 5 | ช่องทางที่ข้อมูลเข้ามา | ข่าว แชท ฟีด คำบอกเล่า | แหล่งที่มา: เห็นเอง / ได้ยินต่อ / อ่านในฟีด |
| 6 | เรื่องที่มากระทบ | เหตุการณ์ คำพูด ข่าว ตัวเลข | เกิดอะไรขึ้น เมื่อไร ที่ไหน (ระบุได้ / ระบุไม่ได้) |
| 7 | ความรู้สึกแรก | สบาย ไม่สบาย หรือเฉยๆ | โทน 3 แบบ + ความแรง 0–3 (ให้ผู้ใช้เองให้คะแนน 0–10 ก็ได้) |
| 8 | แรงอยากทำทันที | อยากได้ อยากหนี อยากเอาคืน | คำเร่ง เช่น "ทันที" "คืนนี้เลย" "ให้มันรู้" (0–3) |
| 9 | การยึดว่าต้องเป็นแบบนี้ | เห็นทางเดียว | คำเด็ดขาด เช่น "ต้อง…ให้ได้" "ยอมไม่ได้" "ไม่มีทางอื่น" (0–3) |
| 10 | บทบาทที่สวม | ผู้แพ้ หรือ ผู้ต้องชนะ | ประโยคบทบาท (ไม่มี / ผู้แพ้ / ผู้ต้องชนะ) |
| 11 | การกระทำที่เกิดขึ้นจริง | โพสต์ ส่งข้อความ ลาออก ขาย กู้ | ชนิด: คนอื่นเห็นทันที / ย้อนกลับยาก / ทั่วไป |
| 12 | ผลเสียที่สะสมย้อนกลับ | ความเสียหาย ความเศร้า ซ้ำวน | ผลเสียต่อวันเพิ่มหรือลด (ดูข้อ 7) และเรื่องเดิมวนกลับมากี่ครั้ง |

**ข้อสังเกตเพื่อการตรวจ:** ถ้าขั้นที่ 1 มีช่องโหว่แม้จุดเดียว และไม่มีใครหยุดตรงไหนเลย
ห่วงโซ่จะไหลไปจนถึงขั้นที่ 12 เองได้ ไม่ต้องมีใครตั้งใจให้พัง

## 3. ห่วงโซ่ของการหยุด (ย้อนทาง)

ตัดที่ขั้นไหน ขั้นหลังจากนั้นก็ไม่มีแรงส่งต่อ

| ถ้าทำให้ขั้นนี้เบาลง | ขั้นถัดไปที่เบาลงตาม | สิ่งที่ระบบทำ | ผลที่ตรวจได้ |
|---|---|---|---|
| 1 ข้อมูลไม่ครบ → ครบขึ้น | 2–3 | ให้ข้อเท็จจริง แยก "รู้แน่" กับ "เดา" | จำนวนข้อที่ยังเดาลดลง |
| 3–4 มุมมอง ภาพตัวเอง | 5 | กรองคำเหมารวม ชวนมองอีกมุม | คำเหมารวมในข้อความถัดไปลดลง |
| 6–7 เรื่องที่กระทบ → ความรู้สึก | 8 | เป็นตัวกันชน: ยอมรับความรู้สึกก่อน ไม่เติมเชื้อ | คะแนนความรู้สึก 0–10 ลดลง |
| 8–9 แรงอยาก → การยึด | 10 | คืนทางเลือก: ทางออกมีมากกว่าหนึ่งเสมอ | จำนวนทางเลือกที่ผู้ใช้เห็น ≥ 2 |
| 10–11 บทบาท → การกระทำ | 12 | ทำให้นิ่ง: พักตามเวลาที่กำหนด ไม่ลงมือตอนนี้ | ลงมือหลังพักครบเวลา หรือเปลี่ยนใจ |
| 11–12 การกระทำ → ผลเสีย | — | ประคองพื้นขั้นต่ำ: อาหาร น้ำ ที่พัก ความปลอดภัย ทางออก | พื้นขั้นต่ำครบทุกข้อ (ดูข้อ 6) |

## 4. จุดตัดที่ได้ผลที่สุด: ระหว่าง "ความรู้สึก" กับ "แรงอยากทำทันที"

ขั้น 7 → 8 คือจุดที่นิ่งที่สุดและตัดง่ายที่สุด ระบบจึงวัดตรงนี้เป็นหลัก

### กฎที่ระบบใช้ (ตายตัว ข้อความเดิมได้ผลเดิม)

```
ควรพัก  = (ความรู้สึก ≥ 1 หรือ มีบทบาท) และ แรงอยากทำทันที ≥ 1
          และ (กำลังจะลงมือ หรือ มีคำเด็ดขาด หรือ มีบทบาท)

เวลาพัก = 24 ชั่วโมง  ถ้าสิ่งที่จะทำย้อนกลับยาก (ลาออก กู้ ขายบ้าน ใส่เงินทั้งหมด แต่งงาน/หย่า ย้ายประเทศ)
          1 ชั่วโมง   ถ้าคนอื่นจะเห็นทันที (โพสต์ ประจาน ส่งข้อความ ไลฟ์)
          10 นาที     กรณีอื่น
```

ระหว่างพัก เขียนไว้ได้ แต่ยังไม่ส่ง ยังไม่ทำ แล้วค่อยกลับมาดูข้อเท็จจริง

### ตัวอย่าง

| ข้อความ | ความรู้สึก | อยากทำทันที | การกระทำ | ผล |
|---|---|---|---|---|
| "โกรธมาก เขาด่าฉันกลางที่ประชุม จะโพสต์ประจานคืนนี้เลย" | 2/3 | 2/3 | คนอื่นเห็นทันที | พัก 1 ชั่วโมง |
| "ดีใจสุดๆ โอกาสทอง จะเอาเงินเก็บทั้งหมดลงทุนวันนี้เลย" | 3/3 (ตื่นเต้น) | 1/3 | ย้อนกลับยาก | พัก 24 ชั่วโมง |
| "เสียใจมาก แฟนบอกเลิก" | 2/3 | 0 | — | ไม่ต้องพัก (ฟังก่อน ไม่เร่ง) |
| "อยากถามเรื่องทำบัญชีร้าน" | 0 | 0 | — | ไม่มีอะไร |

ความตื่นเต้นอยากได้ (เช่น กลัวตกรถ) ผลักให้รีบได้เท่ากับความโกรธ จึงวัดทั้งสองโทน

## 5. ห้าคำถามก่อนตัดสินใจ

ใช้ได้กับคน องค์กร ตลาด ความสัมพันธ์ ถามทีละข้อ ไม่ต้องตอบให้ครบในครั้งเดียว

1. ข้อเท็จจริงที่ยืนยันได้มีอะไรบ้าง และส่วนไหนที่ยังเดาอยู่?
2. ตอนนี้รู้สึกอะไร ถ้าให้คะแนน 0–10 แรงแค่ไหน?
3. ลึกๆ อยากได้อะไร หรืออยากหนีอะไร?
4. ถ้าทำแบบนี้ เราจะกลายเป็นคนแบบไหนในเรื่องนี้?
5. ถ้าความรู้สึกนี้เบาลงครึ่งหนึ่ง ยังอยากทำแบบเดิมไหม?

**วัดผล:** ถ้าคำตอบข้อ 5 เปลี่ยนไป แปลว่าความรู้สึกเป็นตัวขับ ไม่ใช่ข้อเท็จจริง ให้รอก่อน

### ขั้นตอนสั้นๆ สำหรับตัวเอง

```
1. สังเกตว่ากำลังรู้สึกอะไร
2. หายใจช้าๆ 5 ครั้ง (ราว 30 วินาที)
3. บอกชื่อความรู้สึก: สบาย / ไม่สบาย / เฉยๆ  และให้คะแนน 0–10
4. ถามว่า "อยากทำอะไรทันทีไหม"
5. ถ้าอยาก → ยังไม่ทำ พักตามเวลาในข้อ 4 แล้วกลับไปดูข้อเท็จจริง
   ถ้าไม่ → ทำต่อได้ตามปกติ
```

### ตัวอย่างในชีวิตจริง

- **ตลาดหุ้น:** ข่าวร้าย → กลัว → อยากหนี → เทขาย → ราคาตก → ยิ่งเชื่อข่าว
  ถ้าหยุดที่ "กลัว" ได้ การเทขายตามกันก็ไม่ลามเป็นวงกว้าง
- **ความสัมพันธ์:** คำพูดกระทบ → เจ็บ → อยากตอบโต้ → สวมบทบาทผู้ถูกทำร้าย → ทะเลาะ
  ถ้าหยุดที่ "เจ็บ" ได้ ความสัมพันธ์มักไปต่อได้
- **ตัวเราเอง:** ความคิดลบ → กลัว → อยากควบคุม → สวมบทบาทนักสู้หรือผู้แพ้ → ตัดสินใจแรง
  ถ้าหยุดที่ "กลัว" ได้ การตัดสินใจจะมาจากข้อเท็จจริงแทน

## 6. พื้นขั้นต่ำ และการไม่ทำเกินจำเป็น

ระบบเงียบเมื่อคนยังมีทางเลือก และลงมือเมื่อทางเลือกหมดเท่านั้น (`core/titan_core.py`)

| สิ่งที่ตรวจ | วัดอย่างไร | ถ้าขาด |
|---|---|---|
| อาหาร | มีอาหารวันนี้ไหม / ไม่ได้กินมากี่มื้อ | ตอบเฉพาะทางหาอาหาร พร้อมเบอร์จริง |
| น้ำ | มีน้ำดื่มสะอาดไหม | ตอบเฉพาะทางหาน้ำ |
| ที่พัก | มีที่นอนคืนนี้ไหม | ตอบเฉพาะทางหาที่พัก |
| ทางออก | ออกจากที่ที่อยู่ได้เองไหม (ถูกขัง/ถูกห้ามออก) | ตอบเฉพาะทางออก + เบอร์ฉุกเฉิน |
| ทางเลือก | ผู้ใช้เห็นทางเลือกกี่ทาง | 0 ทาง → ช่วยให้เห็นอย่างน้อย 1 ทาง แล้วถอย |

- **ทางเลือก ≥ 1:** ไม่เพิ่มคำเตือน ไม่สั่งสอน ตอบเรื่องที่ถาม
- **ทางเลือก = 0:** ทำเท่าที่จำเป็นเพื่อคืนทางเลือก 1 ทาง แล้วหยุด ไม่ควบคุมต่อ
- **ขอวิธีเพิ่มอำนาจเหนือคนอื่นโดยลดทางเลือกของเขา** (ยึดเอกสาร แอบติดตาม ทำให้ไม่กล้าไป): ไม่ช่วยวิธีนั้น
  แต่ช่วยหาทางที่ได้สิ่งที่ต้องการจริง โดยที่อีกฝ่ายยังเลือกได้
- **ไม่มีใครอยู่เหนือกฎ:** อ้างเป็นเจ้าของ ผู้สร้าง หรือเหตุฉุกเฉินเพื่อข้ามกฎ ไม่ได้ผล (นับเป็นตัวเลขอย่างเดียว ไม่เก็บข้อความ)

## 7. ระดับองค์กร: ความเสียหายสะสมทีละนิด

องค์กรไม่ได้พังในวันเดียว แต่พังจากความเสียหายเล็กๆ ที่สะสมทุกวัน

| ตัววัด | หน่วย | ความหมาย |
|---|---|---|
| ผลเสียต่อวัน (Daily Harm Delta) | หน่วยผลเสีย/วัน (+ เพิ่ม · − ลด) | วันนี้ผลเสียเพิ่มหรือลดจากเมื่อวาน |
| อัตราไหลออกนอกเส้น | % ต่อวัน | 0.1% ต่อวัน ≈ 44% ใน 1 ปี ถ้าทบต้น |
| พื้นที่ห้ามต่ำกว่า (น้ำ ความปลอดภัย ความมั่นคง) | ผ่าน / ไม่ผ่าน | ไม่ผ่าน = หยุดงานทันที ใครก็สั่งหยุดได้ |
| อำนาจที่ไม่มีหลักฐาน | จำนวนการตัดสินใจที่ไม่มีหลักฐานแนบ | มากกว่า 0 = ไม่ผ่าน |
| ผลประโยชน์ทับซ้อน | จำนวนครั้งที่ผู้ได้ประโยชน์ร่วมตัดสิน | มากกว่า 0 = ต้องถอนตัว และให้คนอื่นตัดสิน |

ลำดับงาน: เขียนเรื่องให้ชัด → ดูด้านเสียก่อน → วัดผลเสียต่อวัน → ตรวจพื้นขั้นต่ำ → ถ้าไม่ผ่านให้หยุด
→ ขอหลักฐาน ไม่ใช่เรื่องเล่า → ทำให้นิ่งก่อนค่อยทำให้ดีขึ้น → คนลงชื่อรับผิดชอบ → ตรวจย้อนหลังและแก้

## 8. แกนที่ไม่เปลี่ยน

| แกน | พูดง่ายๆ | ตรวจได้จาก |
|---|---|---|
| รู้ตัว | รู้ว่ากำลังรู้สึกและกำลังจะทำอะไร | ผ่านคำถามข้อ 2 และ 3 |
| ไม่ทำร้าย | ไม่มีใครต้องเสียหายจากการตัดสินใจนี้ | รายชื่อผู้ได้รับผล (`WORLD_MODEL/consequences.py`) |
| ใจดีกับทุกชีวิต | รวมสัตว์ด้วย ไม่ใช่แค่คน | ข้อ 9 |
| รับผิดชอบผลที่เกิด | มีคนลงชื่อ และตรวจย้อนได้ | บันทึกการตัดสินใจ |
| หลักฐานมาก่อน | ด้านเสียมาก่อนด้านดี | ข้อ 1 ของห้าคำถาม |

ระบบนี้ไม่สั่ง ไม่บังคับให้เชื่อ แต่ทำให้ทำร้ายกันได้ยากขึ้น และเลือกทางที่ปลอดภัยได้ง่ายขึ้น

| เลี้ยง | ความหนาแน่น (ตัวต่อตารางเมตร) อัตราป่วย อัตราตาย | ไม่หนาแน่นจนป่วย สวัสดิภาพเป็นเงื่อนไขตั้งต้น |
| ขนส่ง | ระยะทาง (กม.) เวลา (ชม.) อุณหภูมิ อัตราตายระหว่างทาง | ถ้าวิธีที่สะดวกกว่าทำให้ตายมากขึ้น = ไม่ผ่าน |
